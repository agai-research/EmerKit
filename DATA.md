# Data cards
| Dataset | Source | Licence / status | Use |
|---|---|---|---|
| `data/mcp_tools_compact.json` | MCP-tools (Fei et al., MCP-Zero), github.com/xfey/MCP-Zero | as published by the authors; embeddings removed | real catalogue, scaling (C4), gap map (E1) |
| `data/sources/toucan_mcp_servers.tgz` | Toucan server metadata (Xu et al.), github.com/TheAgentArk/Toucan `mcp_servers/` | as published | real catalogue with schemas, MCP annotations, success rates; audit |
| `data/sources/lecturebank2/` | LectureBank 2.0 (Li et al., COLING 2020), github.com/Yale-LILY/LectureBank | as published | data-science concept graph with annotated prerequisites |
| `data/sources/esco/tabiya_esco_v1.1.1.tgz` | ESCO v1.1.1 (European Commission), CSV transformation by Tabiya, github.com/tabiya-tech/tabiya-open-dataset | ESCO: CC BY 4.0 (check the Tabiya repository terms before redistribution) | archetype skills (50 per domain, keyword selection on labels) and demand weights (number of linked occupations, essential = 1, optional = 0.5, floor 1) |
| `data/generated/` | generated by `export_dataset.py` | ours | synthetic educational servers with ground truth, tasks, requests, workflows, archetypes, norms |
| `data/probes/` | generated by `run_llm.py probes-design` | ours | selection probes (2,000 per seed) |
| `data/audit/static_evidence.jsonl` | static analysis of server code from GitHub | ours | audit step 1 |
| `data/traces/` (not committed) | Toucan trajectories, huggingface.co/datasets/Agent-Ark/Toucan-1.5M | Apache-2.0 | co-usage, trace evidence, A7 |
Programming and English concept graphs are expert-authored (CS2023, CEFR), see `emerkit/concepts.py`. Each ESCO skill is attached to the closest concept of its domain by TF-IDF similarity (`emerkit/esco.py`); attachments with low similarity are kept and reported (`concept_sim`).
Synthetic data are declared as synthetic; LLM judgements (docs/pedagogical_parameters.md) are declared as model judgements.
